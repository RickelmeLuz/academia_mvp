🏋️ Academia MVP
[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-tznmubkq)

Sistema desenvolvido para auxiliar na administração de uma academia, com foco na organização, modelagem e gerenciamento de dados.

📌 Sobre o projeto
O Academia MVP foi desenvolvido como projeto de aprendizagem para aplicar conhecimentos de banco de dados e desenvolvimento de sistemas.

O foco principal foi estruturar as informações necessárias para o funcionamento de uma academia, criando tabelas, atributos, relacionamentos e operações de cadastro e consulta.

A interface da aplicação foi desenvolvida com auxílio da plataforma Bolt. Minha principal contribuição foi a estruturação, organização e administração dos dados do sistema.
